## Original mechanics

- Future UTC two-minute windows, distinct from official mining rounds, with server lock before start and historical active-median ranges.
- Original Cozy paws / Cruise control / Full squeek classifications, preserving zero-work naps as an outcome.
- Visual sprint to 60 newly accepted hardware passages; no invented opponents or points from client animation.
- Daily educational history classification with participation points, separate from future-prediction skill.
- Replay from actual retained passage timestamps; visible ranges, evidence and reproducible scores.
- Original vector hamster avatars, neon circuit, responsive arcade UI and accessible dialogs.

## Squeekchain data and proof limits

Typed, schema-validated `/v1/status` and `/v1/measurement/runs` power play. Every scored future interval needs complete eligible hardware evidence and delayed settlement. Source references, installation, timestamps, source digests and segment IDs are retained. Other requested endpoints are implemented as typed diagnostics and tested against actual retrieved snapshots.

These are API-verified hardware measurement outcomes, **not** certified Core settlement. The live API graph differs from the published deployment record as observed 2026-10-31. Chain-backed gameplay is not enabled; no addresses were silently substituted and no transaction was sent. This limitation must remain visible in review materials.

## Architecture

Next.js App Router, strict TypeScript, Tailwind, shadcn-style Radix/CVA primitives, Motion, Lucide, Zod, Drizzle and PostgreSQL. Development uses persistent PGlite; Vercel requires external PostgreSQL. Server-clock locks, unique prediction constraints, serialized transactions, immutable source records, an idempotent award ledger, session cookies, Origin validation and rate limiting enforce the game rules. Anonymous profiles are not fully Sybil-resistant. See `ARCHITECTURE.md`, `GAME_RULES.md`, `API_INTEGRATION.md`, `QA.md` and `DEPLOYMENT.md`.
